# 教学考试平台部署文档

适用环境：内网服务器 **Rocky Linux 9.4**，地址 **192.168.11.103**。  
部署方式：**源码上传 → 服务器编译打包 → Nginx 对外 + Spring Boot JAR 对内**。

当前线上默认库是 **H2 文件库**（已在跑）。MySQL、Kafka 按本文切换或加装。  
业务代码一期**不依赖 Kafka**；Kafka 作为二期消息中间件预留，配置与安装步骤写在本文，避免以后再摸索。

## 2. 中间件清单

在 Rocky 9 上用 `dnf` 安装编译和运行依赖（已在 192.168.11.103 装过）：

```bash
dnf module enable -y nodejs:18
dnf install -y java-11-openjdk-devel maven nginx nodejs npm
```

| 组件 | 版本（本机实际） | 作用 |
| --- | --- | --- |
| JDK | OpenJDK 11.0.25 | 编译、运行后端。路径 `/usr/lib/jvm/java-11-openjdk` |
| Maven | 3.6.3 | `mvn package` 打可执行 JAR |
| Node.js / npm | 18.20 / 10.8 | `npm run build` 打前端 dist |
| Nginx | 1.20 | 对外 80，反代 `/api` |
| H2 | 随 JAR 内嵌 | 当前默认库 |
| MySQL 8 | 需另装 | 正式库，改 profile 后启用 |
| Kafka | 需另装 | 二期消息，业务暂未消费 |

Maven 镜像（`/root/.m2/settings.xml`）走阿里云，npm 走 `https://registry.npmmirror.com`。

固定用 JDK 11，不要用系统 Maven 自带的 JDK 17 去跑进程（编译用 11 或 17 都可以，运行与方案一致用 11）：

```bash
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk
export PATH=$JAVA_HOME/bin:$PATH
java -version
```

## 3. 代码打包方式

**在服务器上源码打包**（推荐，与现网一致）。不要提交 `node_modules/`、`exam-server/target/`、`exam-server/data/`。

### 3.1 后端：Spring Boot 可执行 JAR

```bash
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk
export PATH=$JAVA_HOME/bin:$PATH
cd /opt/exam/exam-server
mvn -B -DskipTests package
```

产物：

```
/opt/exam/exam-server/target/exam-server-1.0.0.jar
```

这是 `spring-boot-maven-plugin` 打出来的 fat jar，内含依赖，直接 `java -jar` 即可。  
`pom.xml` 里 `java.version=11`，`artifactId=exam-server`，`version=1.0.0`。

Windows 开发机打包（仓库自带 Maven）：

```bat
cd exam-server
..\.tools\apache-maven-3.9.9\bin\mvn.cmd -s ..\.tools\settings.xml -DskipTests package
```

### 3.2 前端：Vite 生产包

```bash
cd /opt/exam/exam-web
npm config set registry https://registry.npmmirror.com
npm install
npm run build
```

产物目录 `/opt/exam/exam-web/dist/`（`index.html` + `assets/`）。  
Axios `baseURL` 是 `/`，生产环境请求发到当前域名的 `/api`，由 Nginx 转到 8080。开发环境才走 `vite.config.js` 里对 `127.0.0.1:8080` 的代理。

注意：`<script setup>` 里不能写 `export const`。`Questions.vue` 曾因此导致 `npm run build` 失败，已改为普通 `const`。

### 3.3 更新发布（改代码后）

```bash
# 后端
cd /opt/exam/exam-server
mvn -B -DskipTests package
systemctl restart exam-server

# 前端
cd /opt/exam/exam-web
npm run build
# dist 已是 Nginx root，一般不用重启 Nginx
```

## 4. 部署步骤（源码方式，现网已完成）

### 4.1 上传源码

从开发机打包源码（排除 `.git`、`.tools`、`node_modules`、`target`、H2 数据）：

```bash
tar -czf exam-src.tar.gz \
  --exclude=.git --exclude=.tools --exclude=node_modules \
  --exclude=target --exclude=data --exclude=.cursor \
  -C /path/to/worker_student .
```

服务器：

```bash
mkdir -p /opt/exam
tar -xzf exam-src.tar.gz -C /opt/exam
```

### 4.2 Nginx

站点文件：`/etc/nginx/conf.d/exam.conf`

```nginx
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name _;
    charset utf-8;
    client_max_body_size 20m;
    root /opt/exam/exam-web/dist;
    index index.html;

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }

    location ~ ^/(swagger-ui|swagger-ui\.html|v3/api-docs|h2-console) {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

Rocky 自带 `/etc/nginx/nginx.conf` 里也有一个 `listen 80` 的默认站点，会和 `exam.conf` 抢 80。需要删掉或注释掉该 `server { ... }` 块，只保留 `include /etc/nginx/conf.d/*.conf;`。

```bash
nginx -t && systemctl enable --now nginx && systemctl reload nginx
```

`client_max_body_size 20m` 对应后端上传 Excel 上限 10MB。Vue 是 History 路由，必须 `try_files ... /index.html`。

### 4.3 systemd 后端（当前 H2）

`/etc/systemd/system/exam-server.service`：

```ini
[Unit]
Description=Exam platform backend (source-built jar)
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/exam/exam-server
Environment=JAVA_HOME=/usr/lib/jvm/java-11-openjdk
Environment=SPRING_PROFILES_ACTIVE=h2
Environment=JAVA_TOOL_OPTIONS=-Dfile.encoding=UTF-8
ExecStart=/usr/lib/jvm/java-11-openjdk/bin/java -jar /opt/exam/exam-server/target/exam-server-1.0.0.jar --server.address=0.0.0.0 --server.port=8080
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

`WorkingDirectory` 必须是 `exam-server`，H2 才会写到 `./data/exam`。

```bash
systemctl daemon-reload
systemctl enable --now exam-server
systemctl status exam-server nginx
ss -lnt | grep -E ':80|:8080'
```

`application.yml` 里 `server.address: 0.0.0.0`，否则局域网访问不到 8080。

### 4.4 常用运维

```bash
systemctl restart exam-server
journalctl -u exam-server -f
tail -f /var/log/nginx/access.log
curl -sS http://127.0.0.1/login | head
```

## 5. MySQL 配置与切换

一期默认 `SPRING_PROFILES_ACTIVE=h2`。正式环境改为 MySQL 8。

### 5.1 应用侧已有配置（不用改文件名）

`exam-server/src/main/resources/application.yml`：

```yaml
spring:
  profiles:
    active: ${SPRING_PROFILES_ACTIVE:h2}
```

`exam-server/src/main/resources/application-mysql.yml`（profile=`mysql` 时生效）：

```yaml
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://${MYSQL_HOST:localhost}:${MYSQL_PORT:3306}/exam?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    username: ${MYSQL_USER:root}
    password: ${MYSQL_PASSWORD:root}
  sql:
    init:
      mode: always
      schema-locations: classpath:db/schema.sql
      continue-on-error: true
```

环境变量覆盖默认值：

| 变量 | 含义 | 本机建议 |
| --- | --- | --- |
| `SPRING_PROFILES_ACTIVE` | 改为 `mysql` | `mysql` |
| `MYSQL_HOST` | 库地址 | `127.0.0.1`（库和后端同机） |
| `MYSQL_PORT` | 端口 | `3306` |
| `MYSQL_USER` | 账号 | `exam`（不要用 root 对外） |
| `MYSQL_PASSWORD` | 密码 | 自设，不要提交 Git |

`continue-on-error: true`：表已存在时忽略重复建表。空库时 `DataInitializer` 会写入演示账号。

3306 **只绑内网**，不要映射到公网。

### 5.2 方式 A：本机安装 MySQL 8（Rocky）

```bash
dnf install -y mysql-server
systemctl enable --now mysqld
```

若仓库是 MariaDB 而不是 MySQL 8，改用官方 MySQL 8 源，或用下面的 Docker 方式，保证是 MySQL 8。

登录后建库建用户：

```sql
CREATE DATABASE IF NOT EXISTS exam DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'exam'@'127.0.0.1' IDENTIFIED BY '请改成强密码';
GRANT ALL PRIVILEGES ON exam.* TO 'exam'@'127.0.0.1';
FLUSH PRIVILEGES;
```

导入表结构（可与应用 `sql.init` 二选一，重复执行一般可因 `IF NOT EXISTS` / `continue-on-error` 通过）：

```bash
mysql -uexam -p exam < /opt/exam/sql/schema.sql
```

`/etc/my.cnf.d/` 建议：

```ini
[mysqld]
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci
bind-address = 127.0.0.1
max_connections = 200
```

改完 `systemctl restart mysqld`。

### 5.3 方式 B：Docker Compose（仓库已有）

服务器需先装 Docker。项目根目录 `docker-compose.yml` 只起 MySQL：

```yaml
services:
  mysql:
    image: mysql:8.0
    container_name: exam-mysql
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: exam
      TZ: Asia/Shanghai
    ports:
      - "3306:3306"
    volumes:
      - exam-mysql-data:/var/lib/mysql
      - ./sql/schema.sql:/docker-entrypoint-initdb.d/01-schema.sql
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
    restart: unless-stopped
```

```bash
cd /opt/exam
docker compose up -d mysql
```

初始化只在数据卷为空时执行一次。密码请改掉 `root`。生产把 `ports` 改成 `127.0.0.1:3306:3306`。

### 5.4 改 systemd 切到 MySQL

编辑 `/etc/systemd/system/exam-server.service`：

```ini
[Unit]
Description=Exam platform backend
After=network.target mysqld.service
# Docker 起库时改成：After=network.target docker.service

[Service]
Type=simple
User=root
WorkingDirectory=/opt/exam/exam-server
Environment=JAVA_HOME=/usr/lib/jvm/java-11-openjdk
Environment=SPRING_PROFILES_ACTIVE=mysql
Environment=MYSQL_HOST=127.0.0.1
Environment=MYSQL_PORT=3306
Environment=MYSQL_USER=exam
Environment=MYSQL_PASSWORD=请改成强密码
Environment=JAVA_TOOL_OPTIONS=-Dfile.encoding=UTF-8
ExecStart=/usr/lib/jvm/java-11-openjdk/bin/java -jar /opt/exam/exam-server/target/exam-server-1.0.0.jar --server.address=0.0.0.0 --server.port=8080
Restart=on-failure
RestartSec=5
```

```bash
systemctl daemon-reload
systemctl restart exam-server
journalctl -u exam-server -n 80 --no-pager
```

日志里应出现 MySQL 连接，而不再是 `jdbc:h2:file:./data/exam`。H2 旧数据**不会**自动迁到 MySQL，切库后是空库 + 演示初始化（若 `sys_user` 为空）。

## 6. Kafka 配置（二期中间件，业务暂未接入）

当前 JAR **没有** `spring-kafka` 依赖，不配 Kafka 也能跑考试系统。  
若要在本机预装，用 **Kafka 3.x KRaft**（不再装 ZooKeeper）。

### 6.1 安装（源码/官方包）

```bash
mkdir -p /opt/kafka /data/kafka
cd /opt
# 按官网下载对应包，示例：
# curl -LO https://downloads.apache.org/kafka/3.8.1/kafka_2.13-3.8.1.tgz
tar -xzf kafka_2.13-3.8.1.tgz
ln -sfn /opt/kafka_2.13-3.8.1 /opt/kafka
```

需要本机已有 JDK（Kafka 3.8 建议 JDK 11+，与后端共用 `/usr/lib/jvm/java-11-openjdk`）。

### 6.2 broker 配置

编辑 `/opt/kafka/config/kraft/server.properties`，与本机相关的项改成：

```properties
process.roles=broker,controller
node.id=1
controller.quorum.voters=1@192.168.11.103:9093

listeners=PLAINTEXT://0.0.0.0:9092,CONTROLLER://0.0.0.0:9093
advertised.listeners=PLAINTEXT://192.168.11.103:9092
listener.security.protocol.map=CONTROLLER:PLAINTEXT,PLAINTEXT:PLAINTEXT
inter.broker.listener.name=PLAINTEXT
controller.listener.names=CONTROLLER

log.dirs=/data/kafka/kraft-logs
num.partitions=3
offsets.topic.replication.factor=1
transaction.state.log.replication.factor=1
transaction.state.log.min.isr=1
auto.create.topics.enable=false
```

单机 `replication.factor` 必须为 1。内网才把 `advertised.listeners` 写成 `192.168.11.103`；只本机用可写成 `127.0.0.1`。

初始化存储并启动：

```bash
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk
KAFKA_CLUSTER_ID=$(/opt/kafka/bin/kafka-storage.sh random-uuid)
/opt/kafka/bin/kafka-storage.sh format -t "$KAFKA_CLUSTER_ID" -c /opt/kafka/config/kraft/server.properties

cat >/etc/systemd/system/kafka.service <<'EOF'
[Unit]
Description=Apache Kafka (KRaft)
After=network.target

[Service]
Type=simple
Environment=JAVA_HOME=/usr/lib/jvm/java-11-openjdk
ExecStart=/opt/kafka/bin/kafka-server-start.sh /opt/kafka/config/kraft/server.properties
ExecStop=/opt/kafka/bin/kafka-server-stop.sh
Restart=on-failure
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now kafka
ss -lnt | grep 9092
```

预创建业务 Topic（名称按二期约定，可改）：

```bash
/opt/kafka/bin/kafka-topics.sh --bootstrap-server 127.0.0.1:9092 \
  --create --if-not-exists --topic exam.submit --partitions 3 --replication-factor 1
/opt/kafka/bin/kafka-topics.sh --bootstrap-server 127.0.0.1:9092 \
  --create --if-not-exists --topic exam.score --partitions 3 --replication-factor 1
/opt/kafka/bin/kafka-topics.sh --bootstrap-server 127.0.0.1:9092 \
  --create --if-not-exists --topic exam.oper-log --partitions 3 --replication-factor 1
/opt/kafka/bin/kafka-topics.sh --bootstrap-server 127.0.0.1:9092 --list
```

| Topic | 用途（预留） |
| --- | --- |
| `exam.submit` | 交卷事件 |
| `exam.score` | 阅卷/出分事件 |
| `exam.oper-log` | 操作日志异步落库 |

### 6.3 应用侧配置（接入时再打开）

后端以后加 `spring-kafka` 后，使用 `exam-server/src/main/resources/application-kafka.yml`，并在 systemd 增加：

```ini
Environment=SPRING_PROFILES_ACTIVE=mysql,kafka
Environment=KAFKA_BOOTSTRAP_SERVERS=127.0.0.1:9092
```

示例（文件已放在仓库，**不要在未加依赖时把 kafka 写进 `SPRING_PROFILES_ACTIVE`**，否则启动会因缺少 Kafka 自动配置类失败）：

```yaml
spring:
  kafka:
    bootstrap-servers: ${KAFKA_BOOTSTRAP_SERVERS:127.0.0.1:9092}
    consumer:
      group-id: exam-server
      auto-offset-reset: earliest
      key-deserializer: org.apache.kafka.common.serialization.StringDeserializer
      value-deserializer: org.apache.kafka.common.serialization.StringDeserializer
      enable-auto-commit: false
    producer:
      key-serializer: org.apache.kafka.common.serialization.StringSerializer
      value-serializer: org.apache.kafka.common.serialization.StringSerializer
      acks: all
    listener:
      ack-mode: record

exam:
  kafka:
    topics:
      submit: exam.submit
      score: exam.score
      oper-log: exam.oper-log
```

`pom.xml` 接入时增加：

```xml
<dependency>
    <groupId>org.springframework.kafka</groupId>
    <artifactId>spring-kafka</artifactId>
</dependency>
```

验证：

```bash
/opt/kafka/bin/kafka-console-producer.sh --bootstrap-server 127.0.0.1:9092 --topic exam.submit
/opt/kafka/bin/kafka-console-consumer.sh --bootstrap-server 127.0.0.1:9092 --topic exam.submit --from-beginning
```

## 7. 配置修改对照

| 文件 | 改什么 |
| --- | --- |
| `exam-server/src/main/resources/application.yml` | `server.address=0.0.0.0`，profile 默认 h2 |

## 8. 防火墙与备份

本机 firewalld 当前是关闭的。若打开：

```bash
firewall-cmd --permanent --add-service=http
firewall-cmd --reload
```

不要对公网开放 `3306`、`9092`、`9093`、`8080`。对外只留 `80`（以及 SSH `22`）。

备份：

- H2：停服务后拷贝 `/opt/exam/exam-server/data/`
- MySQL：`mysqldump -uexam -p exam > exam-$(date +%F).sql`
- 至少留 7～30 天

## 9. 故障排查

| 现象 | 处理 |
| --- | --- |
| 打开 IP 仍是 Nginx 欢迎页 | `nginx.conf` 默认 `server` 还在，与 `exam.conf` 冲突 |
| `/admin` 刷新 404 | Nginx 缺少 `try_files ... /index.html` |
| 页面有、登录 502 | `systemctl status exam-server`，看 8080 是否监听 |
| 登录 500 JSON 解析 | 请求体必须是标准 JSON |
| Maven 编译慢/失败 | 确认 `/root/.m2/settings.xml` 阿里云镜像 |
| `npm run build` 报 script setup export | 去掉 `.vue` 里 `<script setup>` 的 `export` |
| 切 MySQL 后连不上 | 检查 `MYSQL_*`、库是否 utf8mb4、3306 是否只监听 127.0.0.1 |
| 误开 kafka profile 起不来 | 先去掉 kafka profile，或补齐 `spring-kafka` 依赖后再打包 |
