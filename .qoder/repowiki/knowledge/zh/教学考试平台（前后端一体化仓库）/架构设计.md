仓库以 exam-server（Spring Boot 2.7 + MyBatis-Plus + JWT）为唯一数据服务，exam-web（Vue3 + Vite + Element Plus）作为教师端与学生端的前端入口，两者通过 /api/** REST 接口通信；默认开发环境使用 H2 文件库并自动写入演示数据，可选切换 MySQL（docker-compose.yml 提供一键启动）。deploy_docs_scripts 提供 Rocky Linux 上的 Nginx/systemd 部署脚本与故障排查文档，将前后端打包产物与数据库组合部署到单机。三子模块围绕同一套 14+ 张表（knowledge_point、question、exam_paper、exam、exam_record、exam_answer、student_knowledge_stat 等）协作：教师端出题组卷并发布考试任务，学生端答题后由后端评分或经阅卷中心人工批阅，最终按知识点聚合学情统计。根目录的 README.md、start-server.bat、start-web.bat 与 docker-compose.yml 构成统一的本地启动入口，考试系统-方案.md 则约定了角色分流、接口契约、题型与学情分析规则，是前后端共同遵循的设计基线。
