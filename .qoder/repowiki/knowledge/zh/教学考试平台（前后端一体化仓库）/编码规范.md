- 前后端通过 Swagger 暴露的 /api/** REST 接口契约协作，所有请求统一返回 { code, message, data } 结构并携带 Bearer Token。
- 角色权限在登录后由后端 JWT 控制，前端根据角色跳转 /admin（教师/管理员）或 /student（学生）路由。
- 题目必须绑定至少一个 knowledge_point，组卷、阅卷与学情分析均基于 question_knowledge 多对多关系进行。
- 考试相关操作（开始、自动保存、交卷、评分）在服务端完成，拉题接口禁止返回正确答案、解析与对错标记。
- 简答题与关键词解释题走独立阅卷流，教师给分后触发 student_knowledge_stat 按知识点权重回写掌握度。
