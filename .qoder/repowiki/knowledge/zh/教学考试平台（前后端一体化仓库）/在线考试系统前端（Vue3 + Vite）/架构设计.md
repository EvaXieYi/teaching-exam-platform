采用典型的 Vue3 SPA 分层结构：入口 `src/main.js` 通过 createApp 挂载 Pinia、vue-router 和 ElementPlus（中文本地化），根组件 `App.vue` 仅渲染 `<router-view/>`。
- 路由层 `src/router/index.js` 使用 `createWebHistory` 按角色划分路由组：`/admin`（教师/管理员，嵌套在 `AdminLayout.vue`）、`/student`（学生，嵌套在 `StudentLayout.vue`）、`/exam/:examId`（全屏答题无侧边栏），并通过 `beforeEach` 守卫实现未登录跳转、角色越权拦截（学生禁入 /admin，教师禁入 /student 与答题页）。
- 状态层 `src/stores/user.js` 用 Pinia 管理 token、用户信息与头像 URL，持久化到 localStorage，并提供 `login/loadMe/logout/homePath` 等动作。
- API 层 `src/api/http.js` 基于 axios 封装统一请求：自动注入 Bearer Token、统一处理后端 `Result.code !== 0` 错误与 401 登出；`src/api/index.js` 按资源域（auth/users/students/questions/papers/exams/marking/scores/logs/student）导出函数，路径与后端 controller 一一对应。
- 视图层按角色分目录 `views/admin`、`views/student`、`views/exam`、`views/login`，共用 `layouts/AdminLayout.vue`、`StudentLayout.vue` 作为页面壳，`components/UserAvatar.vue` 复用头像展示。
- 构建配置 `vite.config.js` 将 `/api` 代理至 `http://127.0.0.1:8080`，开发端口 5173。
