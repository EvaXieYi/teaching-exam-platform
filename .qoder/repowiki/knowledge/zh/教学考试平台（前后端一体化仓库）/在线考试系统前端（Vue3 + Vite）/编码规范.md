- API 调用集中在 `src/api/index.js` 按资源域分组导出，URL 路径与后端 controller 的 `@RequestMapping` 保持一致。
- 所有 HTTP 请求统一走 `src/api/http.js` 的 axios 实例，由拦截器自动附加 `Authorization: Bearer <token>` 并集中处理 401 与业务码非 0 的错误提示。
- 鉴权状态通过 Pinia store（`useUserStore`）管理，token 与 user 对象同步持久化到 localStorage，并在 logout 时清理。
- 路由按角色分组并以懒加载方式引入组件（`() => import(...)`），配合 `beforeEach` 守卫实现登录态校验与角色越权拦截。
- 表单类接口复用同一函数名区分新增与更新：存在 `id` 时走 PUT 更新，否则走 POST 创建（如 saveUser/saveQuestion/saveExam 等）。
- 文件上传通过 FormData 构造并设置 `responseType: 'blob'`，由 http 拦截器放行 blob 响应交由调用方处理。
