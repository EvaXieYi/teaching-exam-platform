- 服务器配置通过 shell 的 heredoc (`cat > file <<'EOF'`) 直接写入 `/etc/nginx/conf.d/exam.conf` 与 `/etc/systemd/system/exam-server.service`，避免外部配置文件管理。
- Maven 与 npm 构建均显式配置国内镜像（阿里云 Maven mirror 与 npmmirror），以规避中央仓库慢的问题。
- Spring Boot 多环境通过 `SPRING_PROFILES_ACTIVE` 环境变量切换（h2/mysql/kafka），systemd unit 中以 Environment 行注入，而非修改 application.yml。
- 部署文档中的每个操作步骤都附带可直接复制执行的 bash 代码块，并在关键位置给出预期产物路径或验证命令（如 `ss -lnt | grep :80`、`journalctl -u exam-server -f`）。
