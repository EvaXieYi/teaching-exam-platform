本模块由三类独立工件组成，无相互依赖：
- `deploy/remote-setup.sh`：一次性初始化脚本，在裸机上创建 `/opt/exam` 目录、写入阿里云 Maven 镜像与 npm 镜像、生成 Nginx 站点配置（静态资源根为 `/opt/exam/exam-web/dist`，`/api` 反代到 127.0.0.1:8080）、禁用系统默认 80 站点，并生成 systemd unit `exam-server.service` 以 H2 profile 启动后端。
- `docs/部署文档.md`：面向运维人员的完整部署手册，覆盖 JDK/Maven/Node/Nginx/H2/MySQL/Kafka 安装、前后端打包命令、systemd 环境变量、profile 切换、防火墙与备份、常见故障对照表。
- `scripts/extract-remote-apis.ps1`：PowerShell 工具，从远程 SPA 首页抓取 JS 资源，用正则提取前端调用的 API 路径并探测 Swagger/OpenAPI 端点，输出报告供接口审计使用。
三者共同围绕“源码上传→服务器编译→Nginx 对外 + Spring Boot JAR 对内”的现网部署模式，依赖方向单向：脚本与文档描述同一套目标环境，脚本是文档中手动步骤的自动化版本。
